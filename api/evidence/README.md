## Reproduce

From the repository root, start the database services, load the CSV, and run:

```powershell
& api/.venv/Scripts/python.exe -m pytest -c api/pytest.ini api/tests Tifare_forecasting/tests --live-databases -q --junitxml=api/evidence/integration-live-tests.xml
& api/.venv/Scripts/python.exe -m databases.scripts.execute_queries_and_export_results
```

The full-record digest was generated by a read-only verification during this session. It covers the four public fields in timestamp order, normalizing demand/temperature to floats and imputation flags to booleans; database IDs and metadata are excluded.

For report screenshots, run Swagger UI against the live server and capture CRUD, latest/range/recent responses with status codes and IDs, then the forecast client's actual JSON. Screenshots of endpoint schemas alone are not execution evidence.
